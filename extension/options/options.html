Template Updater for Overleaf

What it tracks, where every file comes from, and what it has cached.

Behaviour

Overleaf records every change in its own History panel, so updates can be reverted there even without the backup. On failure the panel always stays open so the error can be read.

Cached template files

Upstream files are cached so opening a second project costs no download. The acmart source is a 15 MB archive, but only the files actually needed are kept. A cached file is reused when the package index confirms its version is still current, and otherwise revalidated with a conditional request that usually returns an empty 304.

Tracked templates

Upstream connectivity

Checks that every source is reachable and still returns a real source file. Run this if a scan reports “could not reach upstream”.

Network scope

The extension only ever fetches from ctan.org, mirror.ctan.org, mirrors.ctan.org, portalparts.acm.org, raw.githubusercontent.com and api.github.com. That allowlist is enforced in background.js, not in the registry, so editing the registry cannot widen it. No analytics, no telemetry, no servers of ours.
